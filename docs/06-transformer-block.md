# 06 · Transformer Block：残差高速公路与 FFN

> 对应模块：站点左侧「⑥ Transformer 层间数据流」

## 一句话

一个 Block 的形状游戏极其单调：**输入 `[n, d]`，输出还是 `[n, d]`，中间全是 `[n, d]`**。真正让它强大的，是那条贯穿始终的残差高速公路——每一层只往上面"加"一点增量，而不是"替换"。

## pre-norm 结构

现代主流（LLaMA / Qwen / Mistral）用的写法：

```
h ← h + Attention( LayerNorm(h) )
h ← h + FFN( LayerNorm(h) )
```

原始 Transformer 用的是 post-norm：

```
h ← LayerNorm( h + Attention(h) )
```

看着只差一个括号位置，差别却很大。**pre-norm 的残差通路是"干净"的**——从输入到输出有一条完全不经过任何归一化的直连路径，梯度可以直接无损回传。这就是为什么 pre-norm 能轻松堆到上百层，而 post-norm 在深层会训练不稳，需要小心地做 warmup。

现在几乎没人再用 post-norm 了。

## 数据流的六个子步骤

站点里的动画把一层拆成六步，每一步都值得单独看：

1. **LayerNorm**：把每一行拉回均值 0 方差 1。稳定数值，也让后续注意力的分数尺度可控
2. **Attention**：唯一一处 token 之间发生信息交换的地方
3. **＋ 残差**：把注意力的输出**加到**原表示上（不是替换！）
4. **LayerNorm**：进入 FFN 前再归一化一次
5. **FFN**：升维到 4 倍再降回来，中间过 GELU 非线性。每个位置独立算，token 之间不交流
6. **＋ 残差**：再一次残差相加，一个 Block 结束

**形状从头到尾没变过**，只有 FFN 中间短暂地变成 `[n, 4d]`。这一点很重要：正因为输入输出同形，Block 才能无限堆叠，层数变成一个纯粹的超参。

## 残差流视角

把残差连接画成一条直线，会得到比教科书框图更清晰的视角：

```
h₀ ──────────────────────────────────────────▶ h_L
     │                │                │
     └─+ Attn₁(h₀)    └─+ Attn₂(h₁)    └─+ ...
```

**信息不是在层之间"传递"，而是在一条高速公路上流动，每一层往上面叠加一点东西。**

这个视角能解释很多事：

- 为什么深层能训练：梯度沿着高速公路直达，不需要穿过任何变换
- 为什么层剪枝能奏效：如果某层的增量很小，去掉它损失不大
- 为什么"logit lens"可行：把中间层的表示直接投影到词表，居然能读出有意义的预测——因为整条路径上信息一直是可用的

在站点的「残差贡献」柱状图里，你会看到两个分支的相对幅度都**远小于 1**。这就是"只加一点"的量化证据。

## FFN 才是参数大头

算一下单个 Block 的参数量（忽略 bias 和 LayerNorm）：

```
注意力：W_Q, W_K, W_V, W_O 各 d×d  →  4d²
FFN：   W₁ 是 d×4d，W₂ 是 4d×d    →  8d²
合计                              →  12d²
```

**FFN 占了三分之二。** 加上 GQA 让 KV 投影变小之后，这个比例还会更高。

学界一个主流的观点是：

- **注意力负责信息路由**（谁从谁那里拿信息）
- **FFN 负责知识存储与加工**（拿到之后怎么处理）

支持这个观点的证据包括：编辑模型知识的方法（ROME、MEMIT）都定位在 FFN 层；FFN 的神经元表现出明显的可解释特征（比如"这个神经元对代码里的括号敏感"）。

在站点的柱状图里，FFN 的相对幅度通常明显大于注意力分支——每一层"往箱子里塞的东西"主要来自 FFN。

## 为什么 FFN 要先升维 4 倍

注意力本质上是线性加权平均（softmax 之后乘 V），表达能力有限。FFN 提供的是**非线性变换能力**：

```
FFN(x) = GELU(x·W₁) · W₂      [n, d] → [n, 4d] → [n, d]
```

升维相当于把表示搬到一个更高维的空间，在那里做一次非线性"查表"，再投影回来。维度越高，能表达的特征组合越丰富。

4 倍是个经验值。现在也有用 SwiGLU 的变体，它会引入第三个矩阵，中间维度通常调成 `8/3 × d` 来保持参数量相当。

## 层间相似度：深层在做微调

站点的「层间表示相似度」矩阵有一个很明显的结构：**右下角几乎全白**（相似度接近 1）。

意思是：靠后的层彼此之间表示非常像。模型在深层做的是小幅调整，而不是推倒重来。

推论：

- **层剪枝有理论依据**：如果第 30 层和第 31 层的表示相似度 0.99，去掉一层影响不大
- **早退（early exit）可行**：简单样本不需要走完所有层
- **深层微调更有效**：很多 LoRA 实验发现只调后几层就能拿到大部分收益

同时你会看到：嵌入层（第 0 行）和任何一层的相似度都比较低——毕竟它还没经过任何加工。

## 常见误解

**"层数越多模型越强"** —— 有明确边际递减。层间相似度图已经说明了：深层贡献在变小。同样参数量下，加深 vs 加宽是个需要实验的权衡。

**"残差是为了防止梯度消失"** —— 这是结果不是本质。本质是**让每一层只需要学一个残差增量**，把"从零拟合一个映射"变成"拟合一个接近零的修正"，学习难度大幅下降。

**"LayerNorm 只是稳定数值"** —— 在 pre-norm 里它还承担了另一件事：让残差分支输入的尺度稳定，否则深层累加会导致表示范数爆炸。

## 在站点上怎么玩

1. 点"播放"，看动画走完一个完整 Block 的六个子步骤
2. 停在 `Attention` 那一步，看当前表示热图；再走到 `＋ 残差`，对比变化
3. 停在 `FFN`，注意形状标签变成了 `[n, 4d]`
