## 一条主线

大模型做的事实上只有一件事：**根据前面的 token 预测下一个 token**。

沿着这条线往前推，会自然推出六个模块：

```
要预测下一个 token
  └─ 得先把文本变成数字          → ① 分词
      └─ 变成向量，还得带上顺序    → ② 嵌入与位置编码
          └─ 让 token 之间能交流  → ③ 注意力
              └─ 一层不够，堆很多层 → ⑥ Transformer Block
                  └─ 最后输出一个分布 → ④ 采样（决定抽哪个）
                      └─ 一个一个往外蹦，太慢了 → ⑤ KV Cache
```

## 关于"模拟"这件事

站点里所有数值都是确定性的模拟结果，不是真实模型的前向输出。这一点在每一篇的开头都会被提醒一遍。

需要强调的是：**被模拟的只有"学出来的权重矩阵"，算法流程全是真的**。

- BPE 的合并表是从语料频次里真数出来的；
- 注意力的 Q/K/V 投影、`/√d_k` 缩放、因果掩码、softmax 走的是完整正确的路径；
- 采样三个参数的实现和 HF `transformers` 里的 `TemperatureLogitsWarper` / `TopKLogitsWarper` / `TopPLogitsWarper` 逻辑一致；
- KV Cache 的复杂度分析是解析推导，可以直接和 profiler 对照。

所以用它**建立直觉**是安全的，用它**引用具体数值**是不行的。
